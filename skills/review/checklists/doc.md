# Documentation Review Checklist

Purpose: review documentation for completeness, accuracy against the code, clarity, maintainability, and usability.
Report violations only; severity tags are defaults, adjust with justification.

## Completeness
- [H] 全必須セクションの存在
- [M] API仕様の網羅性
- [M] エッジケースの記載

## Accuracy
- [H] コードとの整合性
- [H] サンプルコードの動作確認
- [M] バージョン情報の正確性

## Clarity
- [M] 明確な言語使用
- [L] 適切な図表の活用
- [L] 一貫した用語使用

## Maintainability
- [L] 更新しやすい構造
- [L] 自動生成部分の明示
- [L] 変更履歴の管理

## Usability
- [M] 適切な対象読者設定
- [M] クイックスタートの提供
- [L] トラブルシューティング情報
